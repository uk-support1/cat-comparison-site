WHOLE-HOME SECURITY

防犯カメラだけで終わらせない。

カメラは抑止・記録の役割。窓や玄関など、住まいの状況に合わせた対策を組み合わせます。

カメラ・録画インターホン

屋外で固定設置し、録画できることを条件にする自治体があります。室内用見守りカメラは対象外の例もあります。

センサーライト・アラーム

人の接近を照らす・知らせる対策。固定方法や屋外設置の条件を確認します。

窓の対策

防犯フィルム・防犯ガラス・面格子・窓補助錠など。CPマークが参考になる制度もあります。

玄関の対策

録画機能付きインターホン、高防犯錠、補助錠など。スマートロックの扱いは自治体ごとに異なります。
