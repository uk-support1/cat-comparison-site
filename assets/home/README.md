# TOP比較カード用写真

ユーザー提供素材「すな.png」「トイレ.png」から作成。保管庫の元画像は変更していません。

| 元画像 | 使用先 | WebPファイル |
| --- | --- | --- |
| すな.png | 猫砂カード | cat-litter-600.webp / cat-litter-1200.webp |
| トイレ.png | 猫トイレカード | cat-toilet-600.webp / cat-toilet-1200.webp |

元の4:3構図を保持して600×450／1200×900に縮小し、WebP品質84で圧縮しています。
表示時のみ共通CSSで3:2にトリミングし、猫の顔・トイレ本体が入るよう上下位置を調整しています。
HTMLのsrcsetで画面幅・画素密度に応じて読み分けます。
