# 猫種プロフィール評価・根拠記録

確認日：2026-10-04。対象：18猫種＋ミックス、全19プロフィール。

## 読み方と限界

これらの1〜5は、複数資料の文章を共通基準で整理した**編集上の目安**である。検証済みの心理尺度、臨床尺度、発症確率、飼育成功率ではない。隣接する点数の差を科学的に有意な差として扱わない。資料間の差、毛の長短、家系、年齢、社会化、健康状態、個体差が大きい。性格の「静かめ」と「おしゃべり」は完全な反対項目ではなく、活動の落ち着きと発声を区別する。

既存の文章・写真・動画・人気ランキングの順序とデザインは維持。性格別ランキングは引き続き `stats` を利用するため、今回修正した点数に応じて掲載順・関連猫種が変わる。

## 採点基準

| 項目 | 1 / 3 / 5 の目安 |
| --- | --- |
| 甘えん坊 | 交流要求が控えめ / 適度 / 人のそば・交流を強く求める |
| 抱っこ・密着 | 抱っこや膝を好みにくい / 個体・場面による / 密着を受け入れやすい |
| マイペース | 常に交流を求めやすい / 両面あり / 自分の場所・時間を大切にする |
| 遊び好き | 活動控えめ / 適度な日課 / 活発で知育・共同遊びも必要 |
| 静かめ | 活動・声の刺激が多い / 中間 / 穏やかな活動傾向 |
| おしゃべり | 発声控えめ / 適度 / 声で頻繁に交流する |
| お手入れ軽め | 日々の集中的な被毛管理 / 定期的・換毛時の追加ケア / 通常の被毛ケアが軽い |
| 抜け毛の少なさ | 非常に多い / 中程度・季節差あり / 比較的少ない。長さだけでなく被毛密度・下毛・換毛を考慮 |
| 毛玉を吐きにくさ | 飲み込む毛への配慮が多い / 中間 / 比較的少ない。猫種別の嘔吐率ではない |
| 留守番のしやすさ | 人との交流をかなり必要とする / 環境・交流時間次第 / ひとり時間にも比較的適応。長期放置を認めない |
| 子どもとの暮らしやすさ | 静かな環境・慎重な交流が特に必要 / 中間 / 社交性・穏やかさ・刺激適応の記述が一致。全猫で大人の見守りと逃げ場が必要 |
| 多頭飼いのしやすさ | 導入に特に慎重 / 相性・導入次第 / 他猫・ペットへの適応記述が一致。相性の保証ではない |
| 初心者向き | 管理・活動・交流の負担が大きい / 通常の準備に加えて配慮 / 気質、運動、被毛、健康管理が比較的取り組みやすい |
| アレルギー配慮度 | 1＝確認資料内に候補としての根拠がない、2＝候補としての言及のみ、3＝小規模な探索研究もある、4〜5＝言及の広がりをさらに吟味する場合の予約値。今回は4・5を使用しない |
| 健康上の注意度 | 1は使用しない。2＝個別・一般ケア中心、3＝追加の家系・体型・管理確認、4＝複数の重要な配慮、5＝体型・遺伝・診療研究などから特に配慮。**高いほど注意事項が多い** |

健康点数は依頼で指定された初期値を採用した。異なる猫種を同一条件で比較した大規模研究から算出した数字ではなく、疾患数だけの合計でもない。アメリカンカール3、ラガマフィン3等も、病気が頻発するという意味ではない。指定になかったサイベリアンは、遺伝子検査資料と通常の健康管理を考慮した暫定3。

毛玉項目は、短毛の多くを4、密な短毛や軽い半長毛を3、長毛・換毛負担が大きい場合を2、毎日の密な長毛管理が必要なペルシャ・ヒマラヤンを1とする保守的な換算。短毛・長毛の変種がある猫種は代表的な被毛からの中間値で、個体の被毛を優先する。嘔吐の実測値は用いていない。5を付けられる猫種別の直接的な比較根拠は確認できなかった。

## 共通の医学・個体差資料

- [Cornell Feline Health Center：ヘアボール](https://www.vet.cornell.edu/departments-centers-and-institutes/cornell-feline-health-center/health-information/feline-health-topics/danger-hairballs)：長毛、換毛、飲み込む毛、過剰な毛づくろい等を考慮。繰り返す嘔吐は猫種のせいと決めず受診相談。
- [AAAAI：Pet Allergy](https://www.aaaai.org/conditions-treatments/allergies/pet-allergy)：真にアレルギーを起こさない猫種はなく、毛の長さ・抜け毛だけでは安全性を判断できない。
- [Sartore et al. 2017：サイベリアンのFel d 1遺伝子](https://pmc.ncbi.nlm.nih.gov/articles/PMC5753643/)：サイベリアン4頭、唾液値は3頭という小規模探索。低い値の個体を猫種全体の性質へ一般化できず、臨床的な安全性の実証でもない。
- [Blue Cross：Hypoallergenic cat myths](https://www.bluecross.org.uk/advice/hyopallergenic-cat-myths)：候補猫種という通説に注意を促す。ロシアンブルー・ベンガルの2は**候補として言及されることだけ**を反映し、低アレルゲンであるという判定ではない。Web取得は検索抄録の確認に限定された。
- [Cats Protection：Choosing a cat](https://www.cats.org.uk/adopt-a-cat/choosing-a-cat)：年齢、性格、家族・他猫との相性と個体別の選択。
- [CFA：Companion Cat World](https://cfa.org/companion-cat-world/)：さまざまな背景の非血統猫。ミックスの共通気質・健康優位は推定しない。

アレルギー点数は他の暮らしやすさ点数と異なり、候補としての言及・研究の有無でしかない。「1より3の猫が安全」という解釈は禁止。全19ページに「猫種だけでは猫アレルギーの有無を判断できません」を表示する。Fel d 1等はすべての猫に存在し、短毛・無毛は安全の理由にならない。既存の一般記事→専門記事の導線は変更しない。

## 実装・保守

`stats`（既存7項目）、`livingStats`（新7項目）、`health: { caution, points, sources }` を全19プロフィールへ設定。共通の `LIVING_RATING_ITEMS` にラベル・説明、`RATING_REFERENCES` と各猫種 `ratingSources` に参照資料を保持し、HTMLは `profile.js` だけで構築する。

個別遺伝子検査は、変異陰性でもすべての疾患を否定するものではない。検査や治療を点数から指示しない。各猫種の実際の飼育履歴・家系・診察に合わせて獣医師と相談する。
